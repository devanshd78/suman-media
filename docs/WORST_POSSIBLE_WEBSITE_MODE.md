# Worst Possible Website Mode

This build is intentionally terrible.

## Scope

The existing Next.js routes, Sanity CMS content, APIs, SEO metadata, links and forms remain in place. A wrapper class is applied only to the public website layout, so Sanity Studio is not intentionally vandalized.

## Deliberate anti-design choices

- Animated rainbow conic-gradient background
- Comic Sans + Papyrus typography collision
- Wavy underlines and multi-color text shadows
- Ridge/groove borders and stacked neon box shadows
- Rotated/skewed sections
- Saturation and hue-rotation on imagery
- Blinking, Windows-95-like buttons
- Clashing header/footer palettes
- Fixed “UNDER CONSTRUCTION” badge
- Scrolling “best viewed at 800x600” ticker
- Excessively colorful Maharashtra-inspired weave treatment
- Intentionally inconsistent card geometry

## Files changed

- `src/app/(website)/layout.tsx`
- `src/app/globals.css`
- `docs/WORST_POSSIBLE_WEBSITE_MODE.md`

No dependency was added and no Sanity schema was changed.
